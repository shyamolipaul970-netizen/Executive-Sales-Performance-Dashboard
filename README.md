# Executive Sales Dashboard | Power BI
## Project Overview
This project presents an interactive Executive Sales Dashboard built using Microsoft Power BI. It provides a consolidated view of sales performance across time periods, countries, sales channels, and product categories.
The dashboard is designed to help business stakeholders monitor key performance indicators (KPIs), identify sales trends, and compare revenue and profitability.

## Key Performance Indicators

Values represent the dashboard's displayed figures and may change when filters are applied.
## Dashboard Features
- Monthly revenue and gross profit trend analysis
- Top five and bottom five countries by revenue
- Sales channel revenue comparison
- Product category revenue distribution
- Geographic visualization of country-level sales
- Interactive filters for quarter, month, product category, and country
## Tools and Technologies
- Microsoft Power BI
- Power Query for data preparation, if used
- DAX for KPI calculations, if used
- Data visualization and business reporting
## Business Objectives
- Monitor overall sales and profitability.
- Identify high-performing and low-performing countries.
- Compare revenue contribution across sales channels.
- Understand product category performance.
- Support data-driven business decisions.
## Key Insights
The dashboard provides a consolidated view of revenue, gross profit, and gross margin.
It also allows users to compare country performance and analyze how sales are distributed across channels and product categories.
